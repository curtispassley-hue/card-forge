CardForge 4D 0.4.1 Alpha

The GitHub Windows workflow runs the core smoke test, regression tests and
source runtime test, then builds and tests CardForge4D.exe before publishing.
Each successful release includes exe-test.json with the packaged test results.

Tests cover synthetic perspective correction, image composition, logo helpers,
watertight and oriented NFC geometry, cavity depth, transformed 3MF instances,
portable project geometry, GUI startup and real OCR with networking disabled.

Not validated: physical printing on the Bambu A1, NFC radio performance after
assembly, and a production HueForge/FlatForge round-trip. The 3D preview is
schematic. Review OCR text and test-fit your actual tag and face before gluing.
