CardForge 4D 0.6 Alpha

The Windows workflow runs source tests, then builds and tests the extracted
folder application. It also runs Microsoft Defender against the app when the
runner provides Defender and records the result in defender-scan.json.

Tests cover direct face solids, named multipart 3MF output, flat exterior
faces, four-color mapping, 30 bundled fonts, GUI controls, responsive export,
offline OCR, geometry and portable projects.

Not validated: physical printing on a Bambu A1, NFC radio performance after
assembly, fine-feature readability with a particular nozzle, or production
fit with a user's tag. Review the slicer preview and test print before gluing.
