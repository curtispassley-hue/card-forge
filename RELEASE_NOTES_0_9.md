# CardForge 4D 0.9 Studio Preview

Select individual image regions with the Wand and assign filament colors like a paint program. The new Paint & refine image workshop includes paint, erase and restore brushes, adjustable brush size and selection tolerance, connected/all-similar selection, grow/shrink/smooth/invert, print-edge threshold, zoom/pan, and local undo/redo. Apply makes one card edit; Cancel leaves the project unchanged.

Filament assignments no longer shift when a palette color changes. Text and painted image regions use stable numbered slots. Background has an independent fifth design-color control and is preserved in exported geometry. Print checks flags five distinct configured colors for four-spool setups. Grayscale is reversible through Restore color; Reset colors restores the default artwork palette.

Portable projects now contain image edits, paint maps and restore pixels. Transparent pixels no longer introduce a dark color fringe at resized logo edges. Front-only inlays, flat exterior surfaces, NFC base, 30 fonts, single-workspace editing and named export destinations are retained.

Download CardForge4D-Windows.zip, Extract All, then run CardForge4D/CardForge4D.exe. Keep its _internal folder beside it. Source is included as a separate ZIP. The workflow tests the source and packaged EXE, performs a Microsoft Defender scan when available, and attaches the results.

This is an unsigned preview. Physical print quality and NFC fit still need a slicer review and test print. Larger images use a disclosed 1600-pixel-per-side workshop copy; original files are preserved. Older releases that already overwrote a saved palette cannot recover its prior colors automatically.
