CardForge 4D 0.5 Alpha

Download CardForge4D-Windows.zip, Extract All, and launch CardForge4D/CardForge4D.exe. Keep the entire folder together, including _internal. No Python installation is needed.

Changes: responsive background HueForge export, lower-memory palette preview, logo scaling and plain-background removal, Undo/Redo, Next/Back, and a cleaner interface with scrollable controls.

The old single self-extracting EXE was reported as a virus on the user's PC. This release uses an extracted-folder package. Protection is not disabled or bypassed. The published defender-scan.json states whether the runner actually scanned it and the result. This is unsigned software; acceptance by every antivirus product is not guaranteed.

Automated tests cover actual GUI controls, responsive export, offline OCR, geometry and portable projects. Physical Bambu A1 printing still requires a test print. Logo removal works best with a plain background; OCR and logo edits should be reviewed.
